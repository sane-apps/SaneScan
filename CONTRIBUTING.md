# Contributing to SaneScan

Thanks for helping. SaneScan is free MIT software.

## Quick start

```bash
git clone https://github.com/sane-apps/SaneScan.git
cd SaneScan
xcodegen generate
./scripts/SaneMaster.rb verify
```

## Good first work

- Fix a labeled `help wanted` issue
- Improve first-scan permission or empty-state copy
- Add a test for OCR, PDF export, or import

Do not add a paywall. Donate stays optional.

## Requirements

- Xcode 16+
- An iOS 17+ simulator
- [XcodeGen](https://github.com/yonaskolb/XcodeGen)
